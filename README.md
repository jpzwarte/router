# Router

A lightweight SPA router implementation for browser applications, built with Lit.

## Features (Coming Soon)

- Simple and intuitive API
- TypeScript support
- Zero dependencies (except Lit)
- History API integration
- Route parameters and query string parsing
- Nested routes support

## Project Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Development Status

This project is currently in initial setup phase. The router implementation will be added soon.
